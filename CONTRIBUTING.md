# Contributing to autoencoder_final

Thank you for your interest in this project!

## Managing Repository Access

### Adding a Collaborator

1. Go to the repository on GitHub.
2. Click **Settings** → **Collaborators and teams**.
3. Click **Add people** and search for the user's GitHub username or email.
4. Select an appropriate role (Read, Triage, Write, Maintain, or Admin) and send the invitation.

### Removing a Collaborator

1. Go to the repository on GitHub.
2. Click **Settings** → **Collaborators and teams**.
3. Find the collaborator you want to remove in the list.
4. Click the **✕** (remove) button next to their name and confirm the removal.

> **Note:** Removing a collaborator revokes their push/pull access to the repository, but does not delete any commits, issues, or pull requests they have already contributed. Their past contributions remain in the project history.

If you are not the repository owner or do not have Admin access, you will not see the Settings tab. In that case, ask the repository owner to perform the removal.

## Submitting Changes

1. Fork the repository and create a feature branch from `main`.
2. Make your changes, following the existing code style.
3. Add or update tests as appropriate.
4. Open a Pull Request describing your changes.

## Code of Conduct

Please be respectful and constructive in all project interactions.
